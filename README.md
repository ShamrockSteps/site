# Shamrock Steps site

The static landing page for [Shamrock Steps](https://www.facebook.com/p/Shamrock-Steps-61556574971561/), a traditional Irish dance school.

## Local preview

No build step is required. From the repository root:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

Vercel can deploy this repository as a static site with its default settings:

- **Framework preset:** Other
- **Build command:** none
- **Output directory:** `.`

The site theme is based on the dark dance shoes and warm wood tones in the school’s public Facebook profile image.
